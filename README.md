# GameVerse 🎮

GameVerse is a full-stack gaming marketplace web application where users can browse, buy, and sell virtual in-game assets. 

## 🚀 Tech Stack
*   **Frontend:** React.js, JavaScript, CSS
*   **Backend:** Core PHP (Custom REST APIs)
*   **Database:** MySQL

## ✨ Features
*   **User Authentication:** Secure login and registration system.
*   **Marketplace:** Browse and filter through various gaming items.
*   **Admin Dashboard:** Manage items, users, and view all transactions.
*   **Responsive Design:** Optimized for both desktop and mobile views.

## ⚙️ How to Run Locally
1. Clone the repository: `git clone https://github.com/dhananjaysingh5276-afk/GameVerse.git`
2. **Backend Setup:** Move the `backend` folder to your XAMPP `htdocs` directory. Import the SQL file from the `database` folder into phpMyAdmin.
3. **Frontend Setup:** Navigate to the `frontend` folder in your terminal, run `npm install`, then `npm start`.
